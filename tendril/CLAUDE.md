# tendril

A readline-style line editor (`DESIGN.md` §5), plus `tendril-demo`. **The library does not depend on
ghostty or tree-sitter.** Only `tendril-test` depends on `ghostty-effectful`, which serves as the
oracle (§1.3, §11.2), and `.hlint.yaml` rule 2 enforces that by module name. The editor arrives in
M2; so far it has its Unicode tables (M2.1) and T0 text: units, the buffer, clusters and widths
(M2.2), held against libghostty's by `Test.Tendril.Text.Oracle` (M2.3); and T1's edit commands,
motions, kill ring, selection and registers (M2.4) and its undo tree (M2.5); T2's keymap
tries and Emacs keymap (M2.6); and T5's host-input decoder (M2.7), held against libghostty's
encoders by `Test.Tendril.Term.Roundtrip` (M2.8).

- `src/Tendril/Text/Unicode/Tables.hs`, `test/Test/Tendril/Text/Unicode/Expected.hs` and
  `test/Test/Tendril/Text/Grapheme/Conformance.hs` are generated by
  `scripts/gen-unicode-tables.py` (§5.3). Do not edit them; change the script and regenerate. CI
  runs it with `--check`.
- Its UCD version is libghostty-vt's, and its width rule is libghostty-vt's: a width that disagrees
  with `Ghostty.Effectful.Unicode.codepointWidth` is a bug in the rule, not in ghostty. So are its
  clusters: `Tendril.Text.Grapheme` is UAX #29 with libghostty-vt's two tailorings (D33), and a
  cluster that disagrees with `Ghostty.Effectful.Unicode.graphemes` is tendril's bug. That API
  leaves clusters with controls (GCB `Control`, `CR`, `LF`) unspecified; compare without them.
- `Offset`'s constructor stays unexported: with it in scope, `coerce` unwraps the newtype and the
  nominal role protects nothing. Test modules import `Offset` abstractly too.
- `tendril-test` has QuickCheck properties and CI runs it with `--quickcheck-replay`; a suite
  without tasty-quickcheck rejects the flag, so it is not added to the other suites' invocation.
- In a test's or doctest's string, a `\x` escape runs on into any hex digit after it: write
  `"\x093C\&a"`, not `"\x093Ca"`.
- **Positions in the editor are code point offsets on cluster boundaries** (D34), not
  `Offset 'Grapheme`: a grapheme offset is counted from the buffer's start. Find boundaries with
  `Tendril.Text.Buffer`'s `clustersFrom`, `clustersBefore`, `floorBoundary` and `ceilingBoundary`,
  which segment from nearby. Never call a `'Grapheme` conversion, `toText` of the whole buffer, or
  `boundaries` of it on a keystroke's path. `EditState` is abstract, and only `apply` and `restore` move the
  cursor and anchor. After an edit it moves them forward (insertion) or back (deletion) to a
  boundary.
- **Did a command change the text?** Compare `EditState`'s `version`, never the buffers (that is
  `O(n)`). `apply`, `restore` and `withBuffer` move it. Undo goes through `Tendril.Edit.Undo`'s
  `Undoable`, which pairs the state with its tree; the editor calls `interrupted` after any of its
  own commands, as it calls `interrupt` on a bare `EditState`.
- **Build ropes with `Buffer.fromText` or `replace`, not `Rope.fromText`**: they chunk the text
  (D34). A rope of one large chunk makes every split near its end walk the chunk.
- **Key chords have one normal form** (D36): build them with `chord`, `key` and the `with*`
  functions, which apply shift to a letter and keep it on any other character, whose shifted form
  depends on the layout. No binding starts with a printable chord; the editor inserts what `typed`
  gives when no prefix is pending. A built-in keymap holds no `conflicts` and no `printableStarts`,
  which its test checks.
- **The input decoder has no clock** (D37): `Tendril.Term.Input` holds bytes that may start a
  longer sequence, and the driver calls `expire` when `waiting` is true and its escape timeout
  passes. Never make it read the time or guess from chunk boundaries: decoding bytes in pieces must
  give the events decoding them whole, which a property holds. An ambiguity the bytes cannot settle
  is settled by the caller (`expectCursorPosition`, `setPixelMouse`), and what it cannot read is
  `Unknown`, never dropped.
- **The roundtrip's `expected` is the model of each encoding** (§11.2): what a mode carries comes
  back exactly, and what it cannot is `Lost` with its reason, which must still decode cleanly. A
  roundtrip failure is a decoder bug unless the mode cannot carry the event; then the model gains
  a `Lost` case whose reason says why, never a looser comparison.
- In a test, a `ByteString` literal keeps only each character's low byte: write a non-ASCII key
  with `encodeUtf8`. `KeyEvent` and `MouseEvent` share `action` and `mods`, so a record update of
  `action` alone is ambiguous; name a field only one of them has too.
- **Benchmarks** (§12.3) are `tendril-bench`, in `bench/Bench/**`. CI gates their allocation
  against `bench/baseline/ghc-9.12.4.csv`.
